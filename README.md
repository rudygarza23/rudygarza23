## Active Directory Lab

![Windows Server](https://img.shields.io/badge/Windows_Server-1976D2?style=for-the-badge)
![Active Directory](https://img.shields.io/badge/Active_Directory-D62828?style=for-the-badge)
![Infrastructure Lab](https://img.shields.io/badge/Infrastructure_Lab-F9C80E?style=for-the-badge)

A hands-on Windows Server system administration project focused on designing, deploying, configuring, and managing an Active Directory domain environment.

The project demonstrates core enterprise IT administration concepts, including centralized identity management, authentication, authorization, Group Policy, network services, file sharing, and PowerShell automation.

### Project Objectives

- Install and configure Windows Server in a virtual lab environment
- Deploy and configure Active Directory Domain Services (AD DS)
- Promote Windows Server to a domain controller
- Configure DNS for Active Directory domain name resolution
- Configure DHCP for automatic IP address assignment
- Create and manage Organizational Units (OUs)
- Create and administer Active Directory user accounts
- Create and manage security groups
- Configure group memberships and user access permissions
- Join Windows client computers to the Active Directory domain
- Create and configure Group Policy Objects (GPOs)
- Apply password and account security policies
- Configure Windows Firewall and basic server security settings
- Configure shared folders and network file access
- Implement NTFS permissions and share permissions
- Use PowerShell to automate common Active Directory administrative tasks
- Troubleshoot domain authentication, DNS, DHCP, and connectivity issues
- Verify Active Directory services and administrative configurations
- Document configurations, commands, screenshots, and troubleshooting procedures

Demonstrate practical Windows Server and Active Directory administration skills through the deployment and management of a centralized domain environment.

## Linux Server Hardening Lab

![Ubuntu Server](https://img.shields.io/badge/Ubuntu_Server-F9C80E?style=for-the-badge)
![Linux Security](https://img.shields.io/badge/Linux_Security-D62828?style=for-the-badge)
![Cybersecurity Lab](https://img.shields.io/badge/Cybersecurity_Lab-1976D2?style=for-the-badge)

A hands-on cybersecurity and Linux system administration project focused on securing an Ubuntu Server environment through security configuration, access control, system monitoring, and vulnerability assessment.

### Project Objectives

- Install and configure Ubuntu Server in a virtual environment
- Manage Linux users, groups, and sudo privileges
- Secure remote administration using SSH
- Implement SSH key-based authentication
- Configure UFW firewall rules to restrict unauthorized network access
- Configure Fail2ban to protect against repeated failed login attempts
- Enable automatic security updates
- Manage Linux file and directory permissions
- Review system logs for security-related events
- Manage and secure Linux system services
- Perform security auditing using Lynis
- Compare security configurations before and after hardening
- Document security configurations, commands, screenshots, and verification results
