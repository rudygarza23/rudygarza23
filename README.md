- Manage Linux users, groups, and sudo privileges
- Secure remote administration using SSH
- Implement SSH key-based authentication
- Configure UFW firewall rules to restrict unauthorized network access
- Configure Fail2ban to protect against repeated failed login attempts

- Manage Linux file and directory permissions
- Review system logs for security-related events
- Manage and secure Linux system services
- Perform security auditing using Lynis
